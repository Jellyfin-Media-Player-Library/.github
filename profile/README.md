# Jellyfin Media Player - Library, Stream, and Queue

## About Jellyfin Media Player

Jellyfin Media Player is a client for a Jellyfin server you operate. Jellyfin Media Player Library is the index you see. Jellyfin Media Player Stream is playback. Jellyfin Media Player Queue is what is next. Jellyfin Media Player Subtitle is captions you chose. Jellyfin Media Player Session is the live connection.

Point only at a host you run or were given. Browse Jellyfin Media Player Library. Start Jellyfin Media Player Stream. Keep Jellyfin Media Player Queue short. Turn on Jellyfin Media Player Subtitle only if you need captions. End Jellyfin Media Player Session when the night ends.

Jellyfin Media Player Library, Jellyfin Media Player Stream, Jellyfin Media Player Queue, Jellyfin Media Player Subtitle, and Jellyfin Media Player Session exist to play a library you already have a right to play.

## Key Features of Jellyfin Media Player

- **Library as the index** – Jellyfin Media Player Library is titles on a server you operate. Jellyfin Media Player Stream plays from it. Jellyfin Media Player Queue pulls from it. Jellyfin Media Player Subtitle is per title. Jellyfin Media Player Session is the connection while you browse.
- **Stream as playback** – Jellyfin Media Player Stream is the session of a title. Jellyfin Media Player Library picks it. Jellyfin Media Player Queue can feed the next. Jellyfin Media Player Subtitle overlays it. Jellyfin Media Player Session is that live play.
- **Queue as what is next** – Jellyfin Media Player Queue is a short list. Jellyfin Media Player Stream continues. Jellyfin Media Player Library still owns titles. Jellyfin Media Player Subtitle can differ per item. Jellyfin Media Player Session still has to start.
- **Subtitle as captions you chose** – Jellyfin Media Player Subtitle is a track you chose. Jellyfin Media Player Stream shows it. Jellyfin Media Player Library still owns the file. Jellyfin Media Player Queue can remember it. Jellyfin Media Player Session unchanged.
- **Session as the live link** – Jellyfin Media Player Session is the connection to a host you run. End it. Jellyfin Media Player Stream then stops. Jellyfin Media Player Library then disconnects. Jellyfin Media Player Queue still sits locally if the client saved it. Jellyfin Media Player Subtitle stops with the stream.

1. **One host** – Point at a server you operate. Open Jellyfin Media Player Library. Play one title as Jellyfin Media Player Stream. Ignore Jellyfin Media Player Queue. Ignore Jellyfin Media Player Subtitle. Glance at Jellyfin Media Player Session.

4. **Short queue** – Pin two titles on Jellyfin Media Player Queue. Play from Jellyfin Media Player Stream. Jellyfin Media Player Library unchanged. Jellyfin Media Player Subtitle still chosen. Jellyfin Media Player Session named.
5. **Review** – Host you run. Jellyfin Media Player Library honest. Jellyfin Media Player Queue short. Jellyfin Media Player Subtitle chosen. Jellyfin Media Player Session ended with the night. Jellyfin Media Player Stream stopped. File dated.
